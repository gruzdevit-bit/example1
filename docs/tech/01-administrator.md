# Инструкция администратора

Администратор работает в браузере на странице «Пользователи» (`/users`).

## Создание пользователя

1. Откройте `/users`.
2. В блоке «Новый пользователь» укажите ФИО, при необходимости e-mail.
3. Нажмите «Создать пользователя». Пользователь появится в списке и станет доступен для выбора в качестве заместителя.

## Создание роли

1. В блоке «Новая роль» укажите название (например, Р4) и описание.
2. Нажмите «Создать роль». Новая роль появится в списке ролей и в формах назначения.

При первом запуске сервис создаёт роли Р1, Р2, Р3 и пользователей А, Б, В, Г, Д. Пользователю А назначены все три роли — на этой связке удобно проверять сценарии замещения.

## Назначение ролей

1. В строке пользователя отметьте одну или несколько ролей.
2. Нажмите «Сохранить роли».
3. Отмеченный набор ролей заменяет прежний набор пользователя. Чтобы снять все роли, снимите все отметки и сохраните.

## Замещения

Пользователь управляет только своими ролями и видит только свои строки замещений. Администратор не получает отдельного экрана управления чужими замещениями: для проверки действий войдите под нужным пользователем через `/login`.

На странице «Мои замещения» видны роли владельца, строки «роль — заместитель — период — статус», кнопки отзыва и блок «Роли, переданные мне». На странице «Я замещаю» заместитель видит переданные ему роли и доступность на текущую дату.
