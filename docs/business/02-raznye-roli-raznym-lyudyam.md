# Инструкция: как передать разные роли разным пользователям

Один пользователь может передать несколько своих ролей разным коллегам за одну настройку.

## Пример: три роли — три заместителя

У пользователя А есть роли Р1, Р2 и Р3. На период с 01.07 по 15.07 он хочет передать:

- Р1 — пользователю Б;
- Р2 — пользователю В;
- Р3 — пользователю Г.

Действия:

1. Откройте «Мои замещения» → «+ Настроить замещение».
2. Укажите период: с 01.07 по 15.07.
3. Отметьте роли Р1, Р2 и Р3.
4. Для роли Р1 отметьте заместителя Б.
5. Для роли Р2 отметьте заместителя В.
6. Для роли Р3 отметьте заместителя Г.
7. Нажмите «Сохранить».

В результате в списке появятся три строки. В период замещения:

- у Б доступна Р1, у В — Р2, у Г — Р3;
- у А роли Р1, Р2 и Р3 недоступны, так как переданы;
- собственные роли заместителей сохраняются.

Если какую-то роль не отмечать, она останется у владельца на весь период. Например, если передать только Р1 и Р2, роль Р3 продолжит быть доступна А.
